# Software Libre

¿Que es el Software Libre?

Es el software libre es el que respeta tu libertad como usuario y la solidaridad social de tu comunidad. En base a esto es un asunto ético, los programas deben respetar la libertad y solidaridad social.

Software Libre es el que respeta las 4 libertades.

	 0. Usar / Ejecutar el programa como quieras, para cualquier fin.
	 1. Estudiar el programa. Cada usuario puede cambiar el código fuente del programa para que haga lo que necesite.
	 2. Distribuir / Ayudar a los demás.
	 3. Mejorar el programa y publicar esas mejoras para beneficio de la comunidad. Hacer copias de tus versiones cambiadas para regalarlas o venderlas cuando quieras.

Si  una de estas 4 libertades falta o es insuficiente el programa es privativo; porque impone un sistema injusto a sus usuarios.
No es una distinción técnica sino ética, social y política.

Usar un programa privativo es dependencia pero usar un programa libre es desarrollo; porque  el programa  libre es conocimiento disponible a lo usuarios, que pueden comprenderlo, adaptarlo y usarlo para otras cosas.
Los programas privativos suelen esconder funcionalidades malévolas, que restringe al usuario, controla al usuario, esto no es raro digamos que es la normalidad en el software privativo.
El propio sistema operativo de Microsoft Windows tiene funcionalidades que envía información a un servidor. Microsoft tiene la potestad de _**"imponer"**_  cambios en el software sin el consentimiento del usuario. Windows es una manera de apoderarse de la máquina del usuario.

Se aprende a programar bien leyendo mucho código y escribiendo mucho código, solo el software libre ofrece la oportunidad de  leer mucho código de  los programas grandes que realmente se usan. Para aprender hace falta comenzar por lo pequeño, pero que es lo pequeño en este contexto, es escribir pequeños cambios en los programas grandes.

Toda entidad pública tiene la obligación y la  responsabilidad  de usar Software Libre,  porque las administraciones públicas no hacen la informática por  si mismas, sino por el pueblo; entonces tienen una responsabilidad ante el pueblo de mantener su control sobre su informática. No tienen que abandonar ese control a las manos privadas de nadie, pero usar un programa privativo en la administración pública es abandonar su control al dueño del programa y así no cumple con su responsabilidad ante el pueblo.
Las entidades del estado que tengan el control de su informática es la soberanía informática del estado.

Lo que opina [[Richard Stallman]] sobre la piratería es que atacar barcos es muy malo, no se debe; pero compartir es otra cosa, compartir es bueno, prohibir a la gente de compartir es malo. Entonces las leyes que intentan aplicar contra compartir son leyes injustas; carecen totalmente de autoridad moral, no merecen obedecerse. Los estado deben eliminar esas leyes para respetar la solidaridad social. Dicen que esas leyes injustas son para apoyar a los artistas, estoy a favor de apoyar a los artistas, porque aprecio lo que escriben, lo que hacen, pero hace falta hacerlo de manera compatible con la práctica de compartir copias de obras.
